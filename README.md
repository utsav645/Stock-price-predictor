# 📈 Stock Price Predictor

A simple Machine Learning web application that predicts stock prices and displays results with a visualization.

⸻

🚀 Features
	•	Predict stock prices for NSE/BSE
	•	User input for prediction duration
	•	Displays predicted values
	•	Generates and shows a graph of predictions
  
  🛠️ Tech Stack
	•	Python
	•	Flask
	•	Pandas
	•	Matplotlib
	•	Machine Learning
  ⚙️ How to Run
  pip install -r requirements.txt
python app.py
